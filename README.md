# 聖書 Bible

旧約・新約聖書を **書名・章・節を選ぶだけですぐ開ける** ビューアです。
日本語2訳・英語1訳を収録し、対訳表示と全文検索ができます。

**公開版 → https://sekiseiji-jpg.github.io/bible/**

| 訳 | 内容 | 収録範囲 |
|---|---|---|
| **口語訳** | 口語訳聖書（1954/1955年）ふりがな付き | 全66巻 1,189章 |
| **新改訳** | 新改訳聖書 新約（1965年版）※ふりがななし | **新約27巻** 260章 |
| **KJV** | King James Version（1769年） | 全66巻 1,189章 |

通信は不要です（本文はすべてアプリ内に保存）。

## 使い方

### 起動する

| 方法 | 手順 | アプリとして追加 |
|---|---|---|
| かんたん | `index.html` をダブルクリック | できません |
| **サーバー経由（推奨）** | Mac: `start.command` をダブルクリック<br>Windows: `start.bat` をダブルクリック | **できます** |

### アプリとして使う（PWA）

`start.command` から開くと、ブラウザの枠なしの独立したアプリとして使えます。

1. **⚙ 設定** → 「アプリとして使う」の **インストール**
   （Safari の場合は共有メニューの「ホーム画面に追加」）
2. 以後は Dock やホーム画面のアイコンから起動できます

**オフラインで読む**

設定の **オフライン用に全文を保存** を押すと、全3訳・約13MB を端末に保存します。
以後は通信がなくても全巻を読めます（10秒ほどで終わります）。

保存しなくても、一度開いた章は自動的に残ります。

**更新**

ファイルを更新すると、次に開いたときに画面下に「新しい版があります」と出ます。
**更新** を押すと最新版で読み込み直します。

### 開きたい箇所を出す

**① 検索ボックスに参照を入力する（いちばん速い）**

```
ヨハネ3:16      よはね3:16      ヨハネによる福音書 3章16節
詩篇23          詩23:1-6        創1:1
John 3:16       jn3:16          1cor13:4
```

- ひらがな・カタカナ・略称・英語名・新共同訳の書名、どれでも引けます
- 候補が出たら `↑` `↓` で選び `Enter` で移動します

**② 書名・章・節のプルダウンから選ぶ**

画面上部の「書名」「章」「節」を選ぶとその場で移動します。

**③ 左の一覧から選ぶ**

旧約／新約を切り替え、モーセ五書・歴史書…の分類から探せます。
上の入力欄に書名の一部を入れて絞り込むこともできます。

### 2つの訳を並べて読む

**対訳**を押すと、表示中の訳と隣の訳が並びます。
隣に並べる訳は **⇄** のプルダウンで選べます。

| 組み合わせ | 使いどころ |
|---|---|
| 口語訳 × KJV | 日本語と英語を照らし合わせる |
| 新改訳 × KJV | 同上（新約のみ） |
| **口語訳 × 新改訳** | **2つの日本語訳の訳し方を比べる** |

新改訳は新約のみなので、旧約の書では新改訳側に収録範囲外である旨を表示します。

### しおりを付ける

| 単位 | 付け方 | 外し方 |
|---|---|---|
| 章 | 本文の上の **🔖 しおり** | もう一度押す |
| 節 | 本文の**節番号**を押す | もう一度押す |

しおりを付けた節は番号に 🔖 が付き、左端に線が入ります。
一覧は左の **しおり** タブに、巻・章・節の順に並びます。
節のしおりには本文の冒頭も一緒に表示されるので、何を栞っていたか一目で分かります。

### しおりにメモを書く

しおりを付けると、その下に **📝 メモを書く** が出ます。押すと入力欄が開きます。

- 書いたメモは本文の中としおり一覧の両方に表示されます
- しおり一覧の **📝** からも開けます
- `⌘`（または `Ctrl`）+ `Enter` で保存できます
- **メモを消す** でメモだけを消せます（しおりは残ります）
- メモのあるしおりを外そうとすると、確認してから消します

### メモを探す

**検索ボックス**に語句を入れると、当てはまるメモがあれば候補の先頭に
**メモ** として出ます。選ぶと一覧が開き、どのメモのどこが一致したかが色付きで分かります。

左の **しおり** タブの入力欄でも絞り込めます。
書名・章節・本文の抜粋・メモの文面のどれでも引っかかります。

### 賛美歌をさがす（♪）

番号を入れると、YouTube や Google の検索が新しいタブで開きます。

1. ヘッダーの **♪** を押す（または `H` キー）
2. お使いの**讃美歌集**を選ぶ（讃美歌1954 / 讃美歌21 / 新聖歌 / 聖歌 など。一覧にないものは自分で入力）
3. **番号**を入れて、次のどれかを押す

| ボタン | 開く検索 |
|---|---|
| 🎤 歌入りを聴く | YouTube（歌つきの演奏） |
| 🎹 演奏のみを聴く | YouTube（オルガン演奏） |
| 📄 歌詞をさがす | Google |

検索ボックスからも呼び出せます。

```
賛美歌312      讃美歌 285      讃美歌21 312      新聖歌90      hymn 100
```

曲集名まで入れると（例: `讃美歌21 312`）、その曲集に切り替わります。
一度さがした番号は「最近さがした番号」に残ります。

> 讃美歌の訳詞と録音は曲集ごとに著作権があるため、このアプリには収録していません。
> 外部サイトの検索を開くだけで、歌詞や音声をアプリ内に保存することはありません。

### 紙の聖書のページ番号で開く

お手元の紙の聖書のページ番号から、同じ箇所を開けます。

**一度だけ、ページを登録してください**

1. **⚙ 設定** → 「紙の聖書のページ」の **ページを登録**
2. どの訳の聖書か選ぶ
3. お手元の聖書の**目次**を見ながら、各書が始まるページを入れる
4. **最終ページ**も入れると精度が上がります

分かるところだけでも構いません。入れた書の間は節数で按分して推定します。

**使い方**

検索ボックスに次のように入れます。

```
p170        170ページ        170頁        170p
```

候補に「170ページ → ヨハネによる福音書 7章10節 あたり」と出るので選びます。
本文の見出しにも「約170ページ」と表示されるようになります。

> ページ番号は版・判型ごとに違うため、聖書データには含まれていません。
> そのため、お手元の聖書に合わせて登録していただく形にしています。
> 書の中は節数からの推定なので、1〜2ページほどずれることがあります。

### 語句を全文検索する

検索ボックスに語句を入れ、候補の **「全文」** を選びます。

- 日本語を入れると表示中の日本語訳、英語を入れると KJV を検索します
  （対訳のまま日本語でも英語でも検索できます）
- 検索範囲は「全巻 / 旧約 / 新約 / この書」から選べます
- 初回だけ全巻の読み込みに数秒かかります（以降は即座に出ます）

### 表示を変える

| ボタン | 内容 |
|---|---|
| **A  18  A** | 文字サイズを 13〜34px の間で変えます（本文のすぐ上） |
| 口語訳 / 新改訳 / KJV | 表示する訳 |
| 対訳 | 2つの訳を左右（スマホでは上下）に並べます |
| ⇄ ○○ | 対訳で隣に並べる訳。**口語訳×新改訳**のように和訳どうしも選べます |
| ⚙ 設定 | 文字サイズ、ふりがな、改行、配色（ライト/セピア/ダーク）、読み上げ速度、紙の聖書のページ登録 |
| 🔊 読み上げ | 表示中の章を音声で読み上げます |
| 📋 コピー | 表示中の章を節番号つきでコピーします |
| 🔖 しおり | **章**をしおりに登録します |
| 節番号 | **節**をしおりに登録します。番号を押すたびに付け外しできます |

### キーボード操作

| キー | 動作 |
|---|---|
| `/` | 検索ボックスへ移動 |
| `−` `＋` | 文字を小さく / 大きく |
| `←` `→` | 前の章 / 次の章 |
| `B` | 書名一覧の開閉 |
| `H` | 賛美歌をさがす |
| `1` `2` `3` | 口語訳 / 新改訳 / KJV |
| `4` | 対訳の切り替え |
| `Esc` | 閉じる・本文に戻る |
| `⌘`/`Ctrl` + `Enter` | メモを保存 |

## 本文データについて

本文は `tools/build_data.py` で変換したものです。

- **口語訳聖書** … 日本聖書協会 1954年（新約）/ 1955年（旧約）。
  出典は [bolls.life](https://bolls.life/)。
  原データのルビは `{漢字|かんじ}` の形で保持し、表示時に `<ruby>` へ展開しています。
  設定でふりがなを消すこともできます。
  **ふりがなが付いているのはこの口語訳だけ**です（他の訳は元データにルビがありません）。
- **新改訳聖書 新約（1965年版）** … 新改訳聖書刊行会。
  出典は [eBible.org](https://ebible.org/find/show.php?id=jpn1965) の USFM。
  **新約聖書のみ**です。著作権は 2015年12月31日に消滅し、
  パブリックドメインとして公開されています。
  1970年の旧新約全書や第二版・第三版・2017年版は著作権が存続しているため収録していません。
- **King James Version** … 1769年版。出典は [bolls.life](https://bolls.life/)。
  原データに付いていたストロング番号（`<S>1234</S>`）と欄外注は取り除いてあります。
- KJV のエステル記に含まれるギリシャ語付加部分（11〜16章）は、
  プロテスタント正典66巻の範囲外のため収録していません。

### 旧約聖書を読むとき

新改訳を選んだまま旧約の書を開くと、収録範囲外である旨と
口語訳へ切り替えるボタンが出ます。書名一覧でも旧約の各書は薄く表示されます。

### 節のまとめ書き

新改訳には、マルコ7:16-17 のように複数の節をまとめて訳している箇所が 15 か所あります。

- 単独表示では節番号を「**16-17**」とまとめて表示します
- 対訳表示では番号を KJV と揃えたうえで、続きの節に「↑ 16節へ」と表示します

### 章立ての違い

**ヨエル書** と **マラキ書** は 2 つの訳で章の区切り方が異なります。

| | 口語訳 | KJV |
|---|---|---|
| ヨエル書 | 4章 | 3章 |
| マラキ書 | 3章 | 4章 |

新改訳の章立ては KJV と同じです。

口語訳はヘブライ語本文の区分を採っています。
対訳表示で片方に章がない場合はその旨を表示します。

### データを作り直す

```bash
python3 tools/build_data.py <JPKJV.json> <KJV.json> <jpn1965_usfm ディレクトリ>
```
